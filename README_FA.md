# پردازشگر محلی ویدیو زنبورک

اپ ویندوزی سبک برای پردازش ویدیو روی سیستم مدیر دوره و ارسال خروجی به هاست دانلود، بدون قرار دادن رمز FTP داخل فایل اجرایی.

## چه کاری انجام می‌دهد

1. از سایت با پروتکل `zanburak-video://process?task={uuid}` باز می‌شود.
2. اطلاعات مجاز Task را از Backend می‌گیرد.
3. فایل خام را با File Picker ویندوز انتخاب می‌کند.
4. با FFmpeg همراه خودش (نه PATH سیستم) ویدیو را به HLS/MP4 مطابق Worker تبدیل می‌کند.
5. خروجی را ZIP می‌کند و قطعه‌ای به Worker می‌فرستد.
6. Worker به FTP هاست دانلود آپلود می‌کند و وضعیت دیتابیس را `processed` می‌کند.

## رابط کاربری

فقط عنوان عملیات، وضعیت، نوار پیشرفت پردازش، نوار پیشرفت آپلود و پیام کوتاه.

## پیش‌نیاز اجرای روی سیستم کاربر

- نصب این اپ (FFmpeg جداگانه لازم نیست)
